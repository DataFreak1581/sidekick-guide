Overview

In this task, you run real user prompts in browser AI assistants and rate them. Each task is rated in two parts: first the user's prompt, then the AI assistant's response.

Run all prompts using the browser AI assistants listed below. Setup steps for each one are in the Setup instructions tab.

Task workflow

Detailed steps

Follow these steps for every task. Do not switch tabs in between.

  1. Set up the browser AI assistant you are using. The steps for each tool are in the Setup instructions tab.
  2. If the task has a URL, open it in a fresh tab and open the AI assistant in that same tab. If the task has only a prompt, open a fresh tab on the browser home page (for example, the Chrome home page) and open the AI assistant there. See Opening the task.
  3. Read the prompt and the shared page, then answer Part 1 (Q1 to Q5). Do not run the prompt yet.
  4. Answer Q6: write a short note on what a good response to this prompt should look like.
  5. Enter the prompt in the AI assistant exactly as written. If the prompt mentions an attachment, file or earlier chat that is not available, still run it as written and leave that context empty.
  6. Read the AI assistant's first response. Answer Q7 and Q8, then select a Q9 rating and write a justification for it. Rate only this first response; do not reply or continue the conversation.
  7. Answer Q10: explain your ratings for Q5, Q7 and Q8.
  8. Submit your answers for all questions on the platform, then move to the next task.

Workflow for every task Cheat sheet

  2. Read the prompt and the shared page, then answer Q1 to Q5.

  4. Enter the prompt exactly as written in the original prompt provided. If it mentions a file or chat you cannot see, run it anyway and leave that context empty.

  7. Do steps 5 and 6 for every chatbot you run the prompt on, then submit.

Part 1: Prompt evaluation (Q1 to Q5)

Answer these five questions before you run the prompt. Base your ratings only on the user's prompt and any page or text shared with it. Each question has a dropdown: pick the score from the table that best matches the prompt.

Q1. Prompt certainty (what the user wants) Dropdown

  1. Definitions:
    1. Prompt certainty measures how clearly the prompt shows what the user wants to achieve (their goal).
    2. You are judging whether the goal is clear, not how well the prompt is written. Writing quality is rated separately in Q3 (Precision).
    3. A prompt can have a clear goal even if it is short or badly written. For example, "tldr" on an article page clearly asks for a summary.
    4. If the wording is so unclear that you cannot tell what the user wants, give a low score in both Q1 and Q3.
  2. Question that can help you select an option from the provided options:
    1. "After reading the prompt, do I know exactly what the user wants, or do I have to guess?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Scores run from 1 (extremely low) to 5 (exceptionally high).
ScoreMeaning
1 Extremely lowNo clear intent, or the text makes no sense. For example, a single stray character or pasted content with no task.
2 LowThe goal is vague or could mean many different things. For example, "help", "check this" or a question cut off mid-sentence.
3 ModerateThe topic or general direction is clear, but key details of the goal are missing, so you would need to make assumptions.
4 HighThe goal is clear and can be acted on, even if it is very short (for example, "tldr"). Only small preferences are left unsaid.
5 Exceptionally highThe goal is fully stated and leaves no doubt about what is being asked.
Examples (5)
  • "c" with a past paper page open: 1. A single letter shows no goal at all.
  • "rectify error" with nothing shared: 2. The user wants an error fixed, but you cannot tell which error or what it is in.
  • "how do i make a program that will answer my stig": 3. The topic is clear, but what the program should do is not defined.
  • "tldr" on an article page: 4. Very short, but clearly asks for a summary of the page.
  • "compare and contrast the different types of protein synthesis inhibitors": 5. The goal is fully stated; there is nothing to guess.

Q2. User-shared context Dropdown

  1. Definitions:
    1. Context is any material that comes with the prompt, such as a web page shared from an open tab (URL) or text pasted into the prompt.
    2. This question checks whether the user gave everything the AI assistant needs to answer.
    3. Some prompts need no context because general knowledge is enough. These get 0, not a low score.
    4. If the prompt refers to something that is not shared, such as an attachment or an earlier chat, treat it as missing.
  2. Question that can help you select an option from the provided options:
    1. "Does the AI assistant have the material it needs, or is something the prompt refers to missing?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Scores run from 0 (not needed) and 1 (completely lacking) to 5 (fully complete).
ScoreMeaning
0 Not applicable/self-containedNo extra context is needed. Gemini can fully answer using general knowledge alone.
1 Completely lackingThe prompt refers to material (such as a file, page or earlier chat) that is missing.
2 Low utilityThe shared URL or text gives very little useful information for the request.
3 Partially completeThe shared context covers the main points of the prompt.
4 Mostly completeThe shared context gives almost everything needed.
5 Fully completeThe shared context gives everything needed to answer the prompt.
Examples (4)
  • "How many barrels of oil is 300,000 tons?": 0. General knowledge is enough; no context is needed.
  • "review my CV and find me the roles relevant to my profile" with a job listing page but no CV: 1. The CV the prompt refers to is missing.
  • "madrid" on a certificate portal page: 2. A page is shared, but it gives little that helps with the request.
  • "Summarize this document" with the document page open: 5. The page contains everything needed.

Q3. Precision (how the user says it) Dropdown

  1. Definitions:
    1. Precision measures how well the prompt is written: the wording, spelling and structure, and how many details or requirements it gives (for example format, length, audience or tone).
    2. It is about how the user asks, not whether the goal is clear. Goal clarity is rated in Q1 (Prompt certainty).
    3. A short or messy prompt scores low here even if its goal is obvious.
  2. Question that can help you select an option from the provided options:
    1. "How exact and well organized is the wording, and does it say what the answer should look like?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Scores run from 1 (very low) to 5 (very high).
ScoreMeaning
1 Very lowBroken, contradictory or misused wording with no logical flow. For example, 1 to 2 word shorthand ("tldr", "codse"), heavy typos, cut-off fragments or no details at all.
2 LowInformal, loosely written or unformatted, with very few requirements. For example, "provide me summary in this article".
3 ModerateClear, everyday wording, but the format, tone or scope is left open.
4 HighWell structured, with clear requirements such as the audience or format.
5 Very highVery specific, technical or structured, with clear requirements, details and formatting rules.
Examples (4)
  • "codse" on a coding problem page: 1. One misspelled word with no details.
  • "i need online jobs": 2. Informal, with no requirements such as skills, location or job type.
  • "Briefly explain: SFP (Small Form-factor Pluggable)": 4. Clear wording with a length requirement ("briefly").
  • A prompt that sets exact steps and an output format, such as "Reply on one line only: INGREDIENT: <name and strength> | SOURCE: <URL>": 5. Detailed rules and a fixed format.

Q4. Task simplicity Dropdown

  1. Definitions:
    1. Task simplicity measures how much work the task needs, assuming the request is clear.
    2. A higher score means a simpler task: 5 is very simple and 1 is highly complex.
    3. Think about the number of steps, the amount of analysis, and whether the user would likely need several rounds of back-and-forth to finish.
    4. Use 0 only when Q1 (Prompt certainty) is rated 1, because the task cannot be understood.
  2. Question that can help you select an option from the provided options:
    1. "If I had to do this task myself, would it take one quick step or many steps and a lot of thinking?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Enter 0 (not "NA") when Q1 is rated 1.
ScoreMeaning
0 Not applicableUse this when Q1 (Prompt certainty) is rated 1, because the task cannot be understood. Enter 0 on the platform.
1 Highly complexA large, multi-part project or strategy that needs deep analysis and several rounds of back-and-forth with the user.
2 ComplexA multi-stage analysis, plan or comparison where working through it with the user adds a lot of value.
3 ModerateA standard task such as combining information, drafting text or explaining several factors, which needs a clear structure.
4 SimpleA single, well-defined step, such as light editing, a standard summary or a straightforward problem.
5 Very simpleA quick lookup, a single fact, a math calculation or a one-line fix.
Examples (5)
  • "yes" with nothing shared: 0. Q1 is rated 1, so the task cannot be judged.
  • "How many barrels of oil is 300,000 tons?": 5. A single calculation.
  • "Summarize this document": 4. One standard step.
  • "compare and contrast the different types of protein synthesis inhibitors": 3. An explanation of several factors that needs a clear structure.
  • A request to create 15 different personal finance templates with formulas: 1. A large, multi-part project.

Q5. Overall prompt confidence Dropdown

  1. Definitions:
    1. Overall prompt confidence brings the goal (Q1) and the context (Q2) together.
    2. It asks whether the AI assistant could give a strong first answer right now, without guessing or first asking the user a question.
    3. Score low when the assistant would have to ask something before it could help.
  2. Question that can help you select an option from the provided options:
    1. "If I were the AI assistant, could I give a good answer straight away, or would I need to ask the user something first?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Scores run from 1 (extremely low) to 5 (exceptionally high).
ScoreMeaning
1 Extremely lowThe prompt is unusable or is missing essential goal or context. Gemini would have to ask a clarifying question before it could help.
2 LowThere are major gaps in the goal or context. A response would need clarification or strong caveats.
3 ModerateThe request is workable. Gemini can give a useful first response while stating its assumptions or offering to refine it.
4 HighThe request is clear and has enough context (in the prompt or a specific shared URL) for a strong response.
5 Exceptionally highThe goal and context are complete and clear. The best possible response can be given immediately.
Examples (3)
  • "give me the lyrics of this song." with nothing shared: 1. The assistant must ask which song before it can help.
  • "i need online jobs": 3. Workable. The assistant can suggest general options while stating its assumptions.
  • "Explain the core ideas about food system transparency from this page using simple bullet points" with that page open: 5. Clear goal and full context, so a strong answer is possible immediately.

Part 2: Response evaluation (Q6 to Q10)

Part 2 has two stages. Answer Q6 before you enter the prompt. Then enter the prompt in the AI assistant and answer Q7 to Q10 based on its first response. Rate only the first response; do not continue the conversation.

Q6. Define response expectations (text, before submitting) Text

  1. Definitions:
    1. Before you run the prompt, write down what you expect a good response to look like.
    2. This gives you a reference point when you rate the actual response in Q7 to Q9.
    3. If the prompt is unclear or missing information, a good response may be the AI assistant asking for more information.
  2. Question that can help you write your answer:
    1. "Before I see the answer, what would an ideal reply to this prompt include or do?"
  3. What to write:
    1. Describe what a good response should contain. Do not write the full response word for word or describe the steps the model takes. This is a text field; there are no rating options.

Also see Writing Q6, Q9 and Q10.

Examples (2)
  • Prompt: "How many barrels of oil is 300,000 tons?" Expectation: "The response should give the approximate number of barrels in 300,000 tons and note that it depends on the type of oil."
  • Prompt: "rectify error" with nothing shared. Expectation: "The response should ask the user to share the error message or the code, because there is nothing to fix yet."

Now enter the prompt in the AI assistant and wait for its first response.

Q7. Collaboration magnitude (dropdown) Dropdown

  1. Definitions:
    1. Collaboration magnitude measures how much the response works with the user instead of only answering.
    2. Collaborative behavior includes suggesting next steps, offering options, asking follow-up questions or inviting the user to refine the answer.
    3. This question only measures how much collaboration there is. Whether that amount was right is rated in Q8 (Collaboration fit).
  2. Question that can help you select an option from the provided options:
    1. "Does the response just answer and stop, or does it involve the user in what happens next?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Scores run from 1 (not at all collaborative) to 5 (extremely collaborative).
ScoreMeaning
1 Not at allGives a direct answer only, with no follow-up, next steps or collaborative language.
2 SlightlyMostly a direct answer, with very little collaborative language or few follow-up options.
3 ModeratelyAnswers the question and suggests relevant next steps, options or improvements.
4 VeryActively involves the user by offering different angles, follow-up questions or ways to build the answer together.
5 ExtremelyWorks as a full partner: guides the user step by step, brainstorms in depth and solves the problem together with them.
Examples (4)
  • The response says "About 2.2 million barrels." and nothing else: 1. A direct answer with no follow-up.
  • The response gives the answer and ends with "Want me to convert this to litres too?": 2. Mostly a direct answer with one small follow-up.
  • A phone comparison that answers the question and suggests "Tell me your budget and main use, and I can recommend one": 3. Answers and suggests a relevant next step.
  • A response to a website-planning request that offers several directions, asks about budget and audience, and proposes building the plan step by step: 4. Actively involves the user.

Q8. Collaboration fit (dropdown) Dropdown

  1. Definitions:
    1. Collaboration fit checks whether the amount of collaboration in the response (rated in Q7) suited what the user needed.
    2. Simple questions usually need a direct answer. Open-ended or complex tasks often benefit from options, questions and next steps.
    3. The scale runs from -2 (way too hands-off) through 0 (exactly right) to 2 (way too hands-on).
  2. Question that can help you select an option from the provided options:
    1. "Given what the user asked, did the response involve them too little, too much or just right?"
  3. Rating:
    1. Select one score from the dropdown. The table below explains when to use each score. Choose a negative score if the response was too hands-off and a positive score if it was too hands-on.
ScoreMeaning
-2 Way too hands-offThe user needed guidance, options or back-and-forth, but got a short, unhelpful direct answer.
-1 Slightly too hands-offAnswered the prompt but missed clear chances to be more helpful or proactive.
0 Exactly rightThe level of collaboration matched what the user needed, whether they said it or not.
1 Slightly too hands-onAdded follow-ups, extra options or chatty text that were not needed when a simpler answer was better.
2 Way too hands-onThe user wanted a quick, direct answer but got a long, intrusive or overly complex response.
Examples (4)
  • The barrels question answered in one clear line: 0. A quick fact needs a direct answer.
  • A phone comparison that answers but never asks about the user's needs, when the best choice depends on them: -1. It missed a clear chance to be more helpful.
  • A request to plan a jewelry selling website answered with one generic line: -2. The user needed guidance and options.
  • The barrels question answered with three paragraphs, several follow-up offers and questions about the user's business: 2. The user wanted a quick answer.

Q9. Overall response quality (dropdown and justification) Dropdown + justification

  1. Definitions:
    1. Overall response quality measures how well the first response helped the user achieve their browsing goal.
    2. Think about whether the user would be satisfied and would come back.
    3. Q9 has two fields: a dropdown rating and a separate justification box.
  2. Question that can help you select an option from the provided options:
    1. "If I were this user, would this response solve my problem, or would I need to ask again or look elsewhere?"
  3. Rating and justification:
    1. Dropdown: select Great, Good, Average, Bad or Horrible. The table below explains when to use each rating.
    2. Justification box: briefly explain why you chose this rating. Say what the response did well and any problems, such as unneeded detail, unhelpful links or not using the shared page.
    3. Explain only your Q9 rating here. Your reasons for Q5, Q7 and Q8 go in Q10.

Also see Writing Q6, Q9 and Q10.

RatingMeaning
GreatThe response cannot be meaningfully improved.
GoodThe response could be improved, but it still does a good job on the user's task.
AverageThe response addresses what the user wants, but problems make it less useful (for example, unneeded detail, unhelpful links or not using the browsing context). The user will likely need to follow up.
BadAt least one major issue makes the response unhelpful.
HorribleSeveral major issues make the response unhelpful and frustrating.
Examples (2)
  • Rating: Good. Justification: "Gave the correct conversion and explained the assumption, but added an unrelated paragraph on oil prices."
  • Rating: Bad. Justification: "The user asked about the open page, but the response ignored the page and gave a generic answer that does not address the question."

Q10. Explanation of Q5, Q7 and Q8 (text) Text

  1. Definitions:
    1. Q10 is a short written explanation of three scores: Q5 (Overall prompt confidence), Q7 (Collaboration magnitude) and Q8 (Collaboration fit).
    2. It is separate from the Q9 justification. Q9 explains the overall quality of the response; Q10 explains these three scores.
  2. Question that can help you write your answer:
    1. "Why did I give these three scores, and what in the prompt or response made me choose them?"
  3. What to write:
    1. Q5: why the prompt did or did not give the AI assistant enough to answer well.
    2. Q7: how collaborative the response was.
    3. Q8: whether that level of collaboration suited what the user needed.
    4. Keep each explanation brief. Do not repeat your Q9 justification. This is a text field; there are no rating options.

Also see Writing Q6, Q9 and Q10.

Examples (1)
  • Prompt: "rectify error" with nothing shared. Explanation: "Q5: 1, the user asks to fix an error but shares no error or code, so the assistant must ask first. Q7: 3, the response asks for the code and suggests common fixes. Q8: 0, asking for the missing code was the right approach."

Writing Q6, Q9 and Q10 Cheat sheet

  • Rule Write in the third person and use "should": "The response should...", not "The model will...".
  • Rule Describe what a good response contains. Do not write the full response word for word or describe the steps the model takes.
  • Rule Write in your own words, specific to the task. No templates, no rephrasing using AI.
AvoidWrite instead

FAQs Cheat sheet

The prompt mentions a file or earlier chat I cannot see. What should I do?

Run it as written and leave that context empty. In Q2, it counts as missing.

The task has no link. Where do I open the assistant?

In a fresh tab on the browser home page (for example, the Chrome home page). See Opening the task.

The assistant asked me a question. Should I answer it?

No. Rate the first response as it is.

Q1 is rated 1. What do I enter for Q4?

0. Do not enter "NA". See Q4.

What is the difference between the Q9 justification and Q10?

Q9 explains your overall quality rating. Q10 explains your Q5, Q7 and Q8 scores. Do not repeat the same text.

Can I use ChatGPT or another AI tool to help write?

No. All ratings and written answers must be your own.

Do I need a screenshot for every chatbot?

Yes. Upload a screenshot and paste the response text for every chatbot. See the Important note.

How is my work checked?

Every task is QC-reviewed. Ratings must match the score tables, so follow them closely.

How am I paid?

$15/hour for every QC-approved task.
